🌳 The Grove of Trials — Enchanted Grove Hackathon Project

Team: Sandra Elza Thomas · Samiyah Harrison · Hannah

"Nourish the forest with knowledge, and illuminate each other with warmth."

A magical study sanctuary: turn your notes into trials, earn Starlight Dew, and hang wishes as glowing stars on the ancient Banyan Memory Tree for other students to find.

✨ Features
Login / Logout (accounts stored in the browser for the demo)
Grove of Trials – paste notes → multiple-choice questions, +100 Starlight Dew per answer, combo streaks, wrong answers return for re-testing (Mist Forest)
Banyan Memory Tree – hanging multicoloured stars with golden lights; write a wish and hang it, click stars to read and "Infuse Energy"
Music Glade – 20 calm study/relax soundscapes generated live with the Web Audio API (no audio files needed)
Milestone magic – showers of stars, fanfare and badges for Dew and concepts-mastered milestones
Forest Awakening – fog lifts as your points grow
Fantasy animation: aurora, moon, swaying pines, falling leaves, shooting stars, glowing mushrooms, cursor fairy, rotating rune circle, 3D tilt cards
🚀 Run locally

Open index.html in a browser. No build step, no installs.

🌐 Deploy on GitHub Pages
Put index.html, style.css, script.js (and this README) in the repo root.
Settings → Pages → Branch main, folder / (root) → Save.
Your site goes live at https://<username>.github.io/<repo>/.
🧠 Notes / Future work
Data (users, notes, points) is saved in localStorage; a backend (Firebase/Supabase) would share the tree across all users.
Question generation is local; the makeQuiz function in script.js is the hook for the Gemini API.
Click anywhere first to start audio (browser autoplay rules).
